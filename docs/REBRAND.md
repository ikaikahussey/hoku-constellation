## Where things live

- Tokens: `app/globals.css` `@theme` block. `--color-*: initial` removes the default Tailwind
  palette so only `ink`, `paper`, `link`, `link-hover`, `muted`, `rule`, `gray-400/300/100` exist.
  `--font-weight-*: initial` leaves `font-normal` and `font-bold`.
- Enforcement: `tests/design-tokens.test.ts` (color literals, legacy palette classes, weights) and
  the `no-restricted-syntax` block in `eslint.config.mjs`. Allowlisted files that must carry literal
  colors: `app/globals.css`, `components/brand/Wordmark.tsx` (SVG fills), `app/api/og/route.tsx`
  (`@vercel/og` renders outside CSS), `app/manifest.ts`.
- Name enforcement: `tests/brand-name.test.ts`.
- Wordmark outlines: generated by `scripts/brand/gen-wordmark.mjs` (opentype.js) into
  `components/brand/wordmark-paths.ts`.

## Font licensing note

Helvetica is not redistributable. The site relies on the system Helvetica / Helvetica Neue where
installed and falls back to Arial. The wordmark outlines were generated from **Liberation Sans Bold**
(SIL Open Font License, metrically compatible with Arial/Helvetica) so no Helvetica glyph data is
shipped in the repository. Re-run `scripts/brand/gen-wordmark.mjs` with a licensed Helvetica Bold file
if the owner holds a web/embedding license and wants exact Helvetica letterforms.

## Accessibility

Black on white exceeds AAA contrast. Red links `#CC0000` on white are 5.9:1 (AA for text, AAA for
large text); links are also underlined in running text so color is not the only cue. Focus rings are
2px black. `tests/e2e/axe.spec.ts` runs axe-core on the main templates.
